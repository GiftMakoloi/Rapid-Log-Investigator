# Deployment Guide: Streamlit Community Cloud

Follow these steps to host this application live on the web for free:

1. Push all project files (`app.py`, `requirements.txt`, `README.md`, `LICENSE`, `.gitignore`, `sample_access.log`) to your public GitHub repository.
2. Navigate to share.streamlit.io and authenticate with your GitHub account.
3. Click "New app" in the dashboard header.
4. Select your repository, set the branch to `main`, and set the Main file path to `app.py`.
5. Click "Deploy!".

Once built, Streamlit will provide a public link to share on your technical portfolio or resume.
